LINA BIRTHDAY WEBSITE — MIXED VERSION

Files:
- index.html
- style.css
- script.js

How to use:
1. Extract this ZIP.
2. Open index.html in Chrome, Edge, Firefox, Safari, or another modern browser.
3. On phones/tablets, you can open the same index.html in the browser.
4. Use “Add your photo” and “Add photos” to choose pictures from your device.
5. Use “Choose song (MP3)” to choose an audio file from your device.

Responsive design:
The layout adapts to mobile phones, tablets, laptops, and desktop screens, including small screens and landscape orientation.

Note:
Photos and music selected through the file pickers are loaded locally in the current browser session; they are not automatically uploaded or permanently embedded into the website. For sharing the site with someone else, you would need to host the site online and include any media files you want them to see.
